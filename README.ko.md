# OptionDeck

[English](README.md) · **한국어**

**Option(⌥)** 을 누르는 동안 Mac 트랙패드를 조절판으로 바꿉니다. 밝기·볼륨·미디어를 조절하고, 앱을 실행하고, 두 페이지에 나만의 기능을 배치할 수 있습니다.

## 빌드하고 실행하기

실행에는 **macOS 14 이상**, 빌드에는 **Swift 6**과 **Rust 1.99 이상**이 필요합니다. 현재 패키징한 앱은 Apple silicon용입니다. 먼저 [Xcode Command Line Tools](https://developer.apple.com/xcode/resources/)와 [Rust](https://rust-lang.org/tools/install/)를 설치하세요.

```sh
git clone https://github.com/a1paka12/OptionDeck.git
cd OptionDeck
zsh scripts/build.sh
open dist/OptionDeck.app
```

스크립트가 Rust 엔진을 빌드하고 네이티브 Swift 앱에 정적으로 연결합니다. 첫 빌드에서는 Cargo 의존성을 다운로드합니다. 빌드된 앱만 받는 사람은 Swift나 Rust를 설치할 필요가 없습니다.

1. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 OptionDeck을 허용합니다.
2. **⌥** 를 잠깐 누르고 있으면 패널이 열리고, 놓으면 원래 작업으로 돌아갑니다.
3. 마우스로 둘러보려면 메뉴 막대 ⌥ → **조절 패널 열기**를 선택합니다.

소스 빌드는 로컬 ad-hoc 서명을 사용하며 공증되지 않았습니다. 직접 빌드하고 신뢰하는 앱이 macOS에서 차단되면 개인정보 보호 및 보안의 **확인 없이 열기**를 사용하세요. 새로 빌드한 뒤에는 현재 앱을 손쉬운 사용에 다시 등록해야 할 수 있습니다.

## 트랙패드 조작

| 동작 | 기능 |
| --- | --- |
| ⌥ 누르고 있기 | 포인터가 있는 모니터에 패널 표시 |
| 한 손가락 좌우 이동 | 값을 바꾸지 않고 기능 찾기 |
| 위아래 이동 | 선택한 슬라이더를 잡은 뒤 조절 |
| 탭 또는 트랙패드 누르기 | 동작 선택 |
| 두 손가락 좌우 스와이프 | 페이지 전환 |
| ⌥ 놓기 | 패널을 닫고 예약한 앱·파일·웹사이트·메뉴 명령 실행 |
| Esc | 예약한 동작 취소 |

원시 트랙패드 조절 중에는 시스템 포인터를 숨기고 고정합니다. Force Touch 지원 기기는 선택·실행·값 조절에 햅틱을 사용할 수 있습니다. 일반적인 Option+문자 단축키는 원래 앱으로 전달됩니다.

## 기능 추가와 배치

메뉴 막대 ⌥ → **앱 및 배치 설정…** 또는 패널의 톱니바퀴를 엽니다.

- **추가:** 왼쪽 기능 보관함에서 원하는 기능을 어느 페이지에나 끌어 넣습니다. 새 칸이 생기고 주변 기능이 자리를 비웁니다. 미리 확보해 둔 빈 칸은 없습니다.
- **이동:** 칸을 끌어 옮깁니다. 놓기 전에 반투명 자리와 주변 칸의 예상 배치를 보여줍니다.
- **크기:** 오른쪽 아래 핸들을 당겨 가로·세로를 조절합니다. Rust 배치 엔진이 주변 칸을 정리하고 슬라이더 최소 크기를 유지합니다.
- **제거:** 칸을 패널 미리보기 밖으로 빼거나 우클릭 → **제거**를 선택합니다. 남은 기능이 공간을 다시 채웁니다.
- **대상 지정:** 앱·파일·폴더·웹사이트·자동화 칸을 클릭해 대상을 지정합니다. 선택 창에서 취소하면 새 칸이 생기지 않습니다.
- **적용:** **저장 및 적용**을 누릅니다. 저장 전에는 편집 화면에만 반영됩니다.

두 페이지 모두 밝기, 볼륨, 통합 미디어, 음소거, 스크린샷 도구, 앱, 파일·폴더, HTTP(S) 웹사이트, 이름으로 실행하는 **macOS 단축어**를 지원합니다. 같은 앱을 여러 번 넣거나 페이지를 전부 비울 수 있습니다. 밝기·볼륨도 어느 페이지에나 추가할 수 있습니다.

기본 1페이지는 밝기·볼륨·통합 미디어입니다. 2페이지는 Chrome, VS Code, cmux, Safari, Notion, 터미널, Finder, 음성 메모, Obsidian으로 시작합니다. 설치되지 않은 앱을 자동으로 설치하지는 않습니다.

### 선택한 앱의 단축키

2페이지의 앱 칸을 가리키면 실행 중인 해당 앱의 실제 메뉴를 macOS 손쉬운 사용 API로 읽습니다. 현재 지정된 키와 사용 가능 상태도 함께 반영합니다. 메뉴에 공개되지 않은 앱 내부 단축키는 이 방식으로 읽을 수 없습니다.

메뉴 명령을 선택하고 ⌥ 를 놓으면 선택한 앱에서 실행합니다. 실행 전에 프로세스·메뉴 경로·제목·키·활성 상태를 다시 확인하며 Esc로 취소할 수 있습니다. 별도의 **macOS 단축어** 기능은 Apple 단축어 앱에 저장된 자동화를 이름으로 실행합니다.

## 음악 앱과 YouTube Music

**설정 → 음악 앱** 또는 패널 상단 음표 버튼에서 기본 음악 앱을 고릅니다. 활성 오디오 출력이 없을 때 재생 버튼을 누르면 이 앱을 엽니다. 이미 출력이 있으면 재생 버튼은 macOS 시스템 미디어 대상을 제어합니다. 현재 재생 중인 대상을 강제로 다른 앱으로 전환하거나 곡을 자동으로 고르는 설정은 아닙니다.

**YouTube Music은 Google Chrome에서 웹앱으로 설치한 경우에만 OptionDeck에서 자동으로 표시됩니다.** 브라우저 탭으로 웹사이트를 열거나 계정만 가지고 있는 것으로는 충분하지 않습니다.

1. **Google Chrome**에서 [music.youtube.com](https://music.youtube.com/)을 엽니다.
2. Chrome의 **앱 설치 / 페이지를 앱으로 설치** 기능으로 YouTube Music을 설치합니다.
3. OptionDeck을 다시 열고, 필요하면 **음악 앱**에서 해당 앱을 선택합니다.

[Google의 웹앱 설치 안내](https://support.google.com/chrome/answer/9658361)를 참고하세요. 다른 설치된 음악 앱도 직접 선택할 수 있습니다.

미디어 위젯은 재생·이전·다음·탐색·재생바를 하나로 묶습니다. 재생바는 음악 앱이 제공하는 실제 접근성 슬라이더에 연결하며, 앱이 진행 위치 읽기와 변경을 허용할 때만 활성화됩니다. 지원하지 않으면 비활성 상태를 표시합니다. 위젯의 시스템 패널 버튼으로 macOS의 실제 재생 컨트롤을 열 수 있습니다. 음악 앱과 브라우저에 따라 지원 범위가 달라질 수 있습니다.

## 개인정보와 지원 범위

설정은 `~/Library/Application Support/OptionDeck/settings.json`에 저장됩니다. OptionDeck 서버·계정·분석 서비스나 유료 API는 필요하지 않습니다. 앱 메뉴는 이 Mac에서 읽으며, 지정한 웹사이트와 자동화는 사용자가 할당한 동작을 수행합니다.

저장소에서는 로컬 설정, 인증정보, 서명 파일, 빌드 캐시, 진단 캡처, 개인 작업 기록과 로컬 앱·ZIP을 제외합니다. README 영상은 일러스트로 제작해 개인 화면 녹화나 개인정보를 담지 않습니다.

밝기와 원시 트랙패드 좌표에는 선택적으로 로드하는 macOS 비공개 프레임워크가 포함됩니다. 지원하지 않는 외장 모니터나 오디오 출력은 비활성화됩니다. 실험적인 네이티브 유틸리티이며, 빌드 성공이 모든 Mac·모니터·음악 앱의 동작을 보장하지는 않습니다.

## 개발

```sh
zsh scripts/test.sh
zsh scripts/build.sh
```

- **Swift / AppKit / SwiftUI:** 네이티브 UI, 손쉬운 사용, 시스템 조절, 햅틱, 입력 처리.
- **Rust:** 설정 검증, 버전 기반 원자적 저장, 프로세스·스레드 잠금, 오래된 응답 차단, 자동 배치.
- **Cargo.lock:** Rust 의존성을 고정합니다. 엔진은 앱에 정적으로 연결합니다.
